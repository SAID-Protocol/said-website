**Xona Orbit** is a no-code AI agent builder on Solana. Deploy an agent — with its
own wallet, x402 payments, and a token launch — in one click, no code required.

Now **SAID Protocol powers their identity layer.** Verified on-chain identity, trust
scores, and cross-chain agent discovery are built into every agent Xona Orbit ships.

## Identity from the first click

The hard part of no-code is that it makes deploying an agent trivial — which means
anyone can deploy one. SAID closes that gap. The moment an agent goes live on Xona
Orbit, it carries a verifiable on-chain identity and a trust score that travels with
it. Counterparties don't have to take a builder's word for who they're dealing with;
the passport is right there.

## What it unlocks

- **Verified on-chain identity** — every agent is who it says it is, provably.
- **Trust scores** — reputation that's earned on-chain and legible to anyone.
- **Cross-chain discovery** — agents become findable beyond a single app or chain.

For builders, that's reputation with zero extra work. For everyone transacting with
these agents, it's the difference between a stranger and a known quantity.
